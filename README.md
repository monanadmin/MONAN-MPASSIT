# MONAN-MPASSIT

Adapted version of **MPASSIT** for use with **MONAN** output, compiled and tested on the **Jaci (INPE)** supercomputer.

Based on the original repository by Larissa Reames: [LarissaReames/MPASSIT](https://github.com/LarissaReames/MPASSIT)

> This repository contains only the *sources* — nearly untouched code, with the minimum modifications necessary to compile and run on Jaci@GNU with ESMF-8.9.0/GNU13.

## About

MPASSIT is a postprocessing tool that interpolates MPAS model output (here, MONAN — Brazil's unified weather/climate model based on MPAS) onto regular grids, enabling further visualization and analysis.

This version keeps the original MPASSIT logic largely unchanged, adjusted only to:
- Compile correctly on Jaci (INPE) with GNU 13 + ESMF 8.9.0/8.9.1;
- Correctly process the diagnostic/history files generated by MONAN.

---

## Main modifications

* Output alternative for writing netCDF files in GrADS format
* Separate variable lists for 2D and 3D fields
* Build adjustments for compilation on Jaci (INPE) with GNU 13 + ESMF 8.9.0/8.9.1

---

## Requirements

- GNU compiler (tested with GNU 13)
- [ESMF](https://earthsystemmodeling.org/) ≥ 8.3.0 (recommended: 8.9.0/8.9.1, built with GNU 13)
- NetCDF library (C and Fortran)
- Access to the Jaci (INPE) supercomputer — or an equivalent environment with the modules above

## Build

**1. Load the module environment:**

```bash
source setenv_jaci_gnu_compile_ESMFjaci.bash
```

**2. Make sure ESMF is available.**

The script above is already set up for use on the Jaci (INPE) supercomputer and loads ESMF 8.9.1 built with GNU 13 directly from the system.

If you want to use your own ESMF installation, set the variables manually before building:

```bash
export ESMF_DIR=/my_dir_to_ESMF-dir/esmf-8.9.1
export ESMF_LIBDIR=${ESMF_DIR}/lib
export ESMF_MODDIR=${ESMF_DIR}/mod
export LIBRARY_PATH=${LIBRARY_PATH}:${ESMF_LIBDIR}
export PATH=${PATH}:${ESMF_DIR}/bin
```

> **Note:** the `NETCDF` and `ESMFMKFILE` variables must also be set:
> - `NETCDF` → main directory of your NetCDF installation (already configured in `setenv`)
> - `ESMFMKFILE` → full path to the `esmf.mk` file of your ESMF installation

**3. Build:**

```bash
./compile.sh
```

The `mpassit` executable will be generated in the `bin` folder.

## Running

### Required files

Create a run directory (`run`) containing the following files (see examples in `parm`):

| File | Description |
|---|---|
| `varlist_2d` | Namelist with the 2D variables to be postprocessed |
| `varlist_3d` | Namelist with the 3D variables to be postprocessed |
| `namelist.input` | MPASSIT namelist, with options already adjusted for MONAN |
| `mpassit_submit.bash` | Job submission script |
| `mpassit` | Executable generated during the build (available in `bin`) |
| `setenv_jaci_gnu_compile_ESMFjaci.bash` | Script that sets up the environment to run MPASSIT |

### Example: `namelist.input`

> Adjust the paths below to match your own environment before running.

```fortran
&config
 grid_file_input_grid = "/my_dir_to_init_file/x1.5898242.init.nc"
 diag_file_input_grid = "/my_dir_to_model_output_file/MONAN_DIAG_G_MOD_GFS_2026012000_2026012000.00.00.x5898242L55.nc"
 hist_file_input_grid = ""
 output_file          = "./monan-mpassit-output.nc"
 block_decomp_file    = "/my_dir_to_graph_info_partition_file/x1.5898242.graph.info.part.128"
 interp_diag          = .true.
 interp_hist          = .false.
 wrf_mod_vars         = .false.
 output_grads         = .true.
 esmf_log             = .true.
 target_grid_type     = 'lat-lon'
 is_regional          = .false.
 nx                   = 3601
 ny                   = 1801
 stand_lon            = 0.0
/
```
